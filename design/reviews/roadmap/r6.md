## Findings
### E50 [major] The WP-11 forcing-only test does not fix the forcing support or the initial velocity; with a single forced mode from rest, an `E_K` rate that drops `ρ` passes (resolution of r5 E45 fails)
- Where: ROADMAP:178 ("OU forcing with a compressive fraction ... Formulas that drop `ρ` pass at `ρ = 1` but fail here by about 6%"); ADR-0018:7; CLAUDE.md "Workflow for a work package", step 2 ("small hand-checkable examples (single Fourier modes, …)").
- Evidence: `r6-E50.jl` (N = 32, seed 11, `u` from rest, so `u` stays in the span of the support). Error of the mutant `⟨u·f⟩ + ½Δt⟨|f|²⟩` in units of the test tolerance scale `eps·E_K/Δt`:
  ```
  single mode (4,0)    text 2.38   E_K mutant 2.38      (1.9e-12 of rate)   Omega mutant 1.7e9
  modes (4,0),(0,4)    text 0.75   E_K mutant 0.751     (1.2e-12 of rate)   Omega mutant 2.5e10
  band(4,6)            text 2.13   E_K mutant 3.6e10    (0.055 of rate)     Omega mutant 2.3e10
  ```
  Reason: `⟨(ρ − 1) u·f⟩ = 0.1⟨cos(x+y) u·f⟩` is nonzero only if `u·f` has a `±(1,1)` component. From rest, `u·f` and `|f|²` hold only sums and differences of support modes. A support without two modes that differ by `±(1,1)` therefore cancels every `ρ` factor in the `E_K` rate. The `Omega` mutant is caught on every support, but on single modes only by `⟨1/ρ⟩ − 1 = 0.5%`, not 6%.
- Consequence: the project workflow steers the WP-11 agent to single Fourier modes. With that choice the r5 E45 defect (a compressible `inj_E_kin` without `ρ`) passes every blocking test again and reaches production `global.nc`.
- Hint: fix the support (for example `band(4, 6)` on `N = 32`) or a broad-band initial `u`, and make the test also evaluate the `ρ`-free formula and require that it fails.
