# Time stepper in the workspace and Lawson stage combinations

Date: 2026-11-19. Status: accepted.

WP-7 fixes the parts of the time stepping that ADR-0005 and the ROADMAP leave open.

- **The scheme reaches `step!` through the workspace.** `Workspace(grid, state; scheme = RK4(), integrating_factor = true)` builds a `TimeStepper` in the field `stepper`. It holds the scheme, the integrating-factor (IF) switch, the stage combinations and the stage buffers. `step!(state, problem, workspace, Δt)` keeps the ROADMAP signature. The WP-13 call `Simulation(...; scheme, integrating_factor, Δt)` passes the two keywords to `Workspace`. The stage buffers are work arrays of the time loop, so they belong in the workspace (WP-4 rule). The `Problem` stays the set of inputs of the right-hand side.
- **Minimal hook set of `step!`.** `step!` reads `problem.forcing`, `problem.rates` and `workspace.stepper`. It calls `update_forcing!(problem.forcing, …)`, `record_injection!(problem, …)`, `rhs!`, and `linear_tendency!` or `propagate!` on `problem.rates`. A test problem needs a struct with `forcing = NoForcing()` and `rates`, one `rhs!` method, and a workspace `(stepper = TimeStepper(scheme, IF, fields),)`. The one-mode test reuses `IncompressibleRates` with a 1×1 rate array, so the production `linear_tendency!` and `propagate!` run.
- **Lawson form in the original variable.** A stage value is `E(c_iΔt)û_n + Δt Σ_j a_ij E((c_i − c_j)Δt) N_j`, with `E(τ) = e^{Lτ}`. `step!` adds the terms in increasing `c_j` and propagates the partial sum between successive nodes (Horner scheme). This takes one `propagate!` per distinct node and no extra buffer. The alternative stores `E(−c_jΔt)N_j` (the transformed variable). It needs fewer passes, but it multiplies every tendency by `e^{σc_jΔt}`. That factor overflows Float32 for `σΔt > 88`, which a viscous run with the IF can reach. The Horner form grows only where the Lawson scheme itself needs it: SSPRK3 has `c_3 < c_2`, so its third stage applies `E(−Δt/2)`.
- **Storage.** One tendency buffer per stage and one stage-state buffer, each a set of spectral fields: 5 sets for RK4. The first stage evaluates `rhs!` on the state itself (`c_1 = 0`). At `N = 2048`, Float64, incompressible, this is 336 MB.
- **Stage time.** The stage state carries `t_n + c_iΔt` and step `n`. No current `rhs!` reads them; the forcing reads the step-start values in `update_forcing!`.
- **Order test on the finest pair.** The one-mode order is `log₂(err(Δt)/err(Δt/2))` at `Δt = 1/80`. At coarser steps RK4 with the IF converges faster than `Δt⁴` (fitted slope 4.5 over `1/10 … 1/80`).
