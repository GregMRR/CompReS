intermittency at different Mach numbers. I want you to lay down the design for

parallel with threads on CPU, GPU nvidia and GPU AMD. CPU and GPU nvidia can be tested on
this machine and will form the basis for each test pass/reject status building
the codebase, all the test for the GPU AMD have to be written and stored to be
run in a second moment. The GPU kernels must be written with the KernelAbstractions.jl package, so the same code runs on NVIDIA and AMD. 
The code has to be modular, and each module must be
thoroughly tested on simple, human inspectable examples. The code must be

gathering context to satisfy an update request is cheap token-wise and quick.
A CLAUDE.md file will serve as an entry point in the project structure, its
logic and its writing guidelines. Design choices of this and future phases are

decisions.  The code has to be optimized for speed, knowing that
vast and well resolved simulations will be the end objective. Between two
design choices on par regarding speed, the minimalistic one is to be preferred
(if it does not present other undesirable characteristics). The datatype has

are the three classes: GLOBAL, containing total energy and enstrophy, SPECTRAL,

Kolmogorov flow type, Ornstein-Uhlenbeck process, random
