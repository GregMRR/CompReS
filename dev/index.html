CompReS

CompReS is a Julia pseudospectral solver for forced-dissipated 2D turbulence. It covers the incompressible and the compressible (low Mach) model. Its purpose is to study intermittency as a function of the Mach number. One source runs on CPU threads, NVIDIA GPUs and AMD GPUs.

A run is a short Julia script against the package API. There is no input-file format.
