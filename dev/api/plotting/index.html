Plotting functions

The core package declares the generic functions; the extensions CompReSMakieExt and CompReSPlotsExt add the methods (ADR-0012). This page lists every documented plotting function, wherever its source file defines it.

CompReS.animate_snapshots — Method
animate_snapshots(outdir, file; field = :omega, spectrum = :E_kin_inc_k, framerate = 10, decades = 12,
                  library) -> file

Write an animation of the FIELDS snapshots of the output directory outdir to the file file and return file. The file extension of file selects the format, for example .mp4 or .gif. Each frame shows field of one snapshot, as plot_field draws it, and, unless spectrum is nothing, the shell spectrum spectrum of outdir/spectral.nc at the record nearest to the snapshot time, as plot_spectrum draws it. The frames follow the snapshot index.

All frames share one colour range (the extrema of field over all snapshots) and one spectrum axis, which spans decades decades below the largest spectrum value over all records, so the frames show the evolution of the spectrum tail. framerate is in frames per second.

The keyword library selects the plotting extension, :Makie or :Plots, as in plot_field.

CompReS.plot_field — Method
plot_field(path; field = :omega, library) -> figure

Plot one physical-space field of a FIELDS snapshot as a colour map over the grid points, with the time of the snapshot in the title. path is a snapshot file snap_NNNNNN.nc or an output directory; for an output directory the function takes the snapshot of the highest index in path/fields. field is a field of the snapshot (:ux, :uy, and :rho in the compressible model) or :omega, the vorticity

\[\omega = \partial_x u_y - \partial_y u_x,\]

which the function computes spectrally from ux and uy on the CPU (specification, Conventions). A field with values of both signs gets a colour range symmetric about zero.

The keyword library selects the plotting extension: :Makie (loaded by using CairoMakie or using GLMakie) returns a Makie.Figure, :Plots (loaded by using Plots) returns a Plots.Plot. The default is the only loaded extension; the function throws an ArgumentError when none or both are loaded.

CompReS.plot_global — Method
plot_global(path; names = nothing, library) -> figure

Plot GLOBAL diagnostics against time, one panel per diagnostic. path is a file global.nc or an output directory. names are the diagnostics to plot; nothing selects every diagnostic of the file. The injection rates are NaN at the start time of each run segment (ADR-0024); the plot leaves those points out.

The function throws an ArgumentError for a name that is not in the file.

The keyword library selects the plotting extension: :Makie (loaded by using CairoMakie or using GLMakie) returns a Makie.Figure, :Plots (loaded by using Plots) returns a Plots.Plot. The default is the only loaded extension; the function throws an ArgumentError when none or both are loaded.

CompReS.plot_spectrum — Method
plot_spectrum(path; names = nothing, time = nothing, library) -> figure

Plot shell spectra of a SPECTRAL file on log–log axes against the shell centres shell_k, with a vertical line at the largest retained wavenumber $k_{\max}$. path is a file spectral.nc or an output directory. names are the spectra to plot; nothing selects every variable of the file whose coordinate is shell_k. time selects the record nearest to that time; nothing selects the last record. The axes leave out the shell $k = 0$ and every value that is not positive.

The function throws an ArgumentError for a name that is not in the file or whose coordinate is shell_edge (a flux, which takes both signs).

The keyword library selects the plotting extension: :Makie (loaded by using CairoMakie or using GLMakie) returns a Makie.Figure, :Plots (loaded by using Plots) returns a Plots.Plot. The default is the only loaded extension; the function throws an ArgumentError when none or both are loaded.
