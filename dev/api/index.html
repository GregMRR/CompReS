API reference

CompReS.CompReS — Module
CompReS

Pseudospectral solver for forced-dissipated 2D turbulence, compressible (low Mach) and incompressible, on CPU threads, NVIDIA GPUs and AMD GPUs.

source
CompReS.Compressible — Type
Compressible(; eos, μ, ζ, κ = 0, large_scale = LargeScaleDissipation(), nonlinear = true)

Compressible model with the equation of state eos, shear viscosity μ, bulk viscosity ζ, density diffusivity κ and the LargeScaleDissipation large_scale.

The small-scale dissipation $\rho^{-1}(\mu\nabla^2\mathbf{u} + \zeta\nabla\theta)$ splits into a linear part with $\rho_0 = 1$ and an explicit remainder (ADR-0004). The linear part is diagonal in the Helmholtz basis (specification, compressible model, Fourier form):

\[\partial_t \hat{\mathbf{u}}^s = -\big(\mu k^2 + \alpha k^{-2m}\big)\hat{\mathbf{u}}^s, \qquad \partial_t \hat{\mathbf{u}}^c = -\big((\mu + \zeta) k^2 + \alpha k^{-2m}\big)\hat{\mathbf{u}}^c, \qquad \partial_t \hat\rho = -\kappa k^2 \hat\rho .\]

nonlinear = false is a test switch: the right-hand side then drops the advection, the pressure, the viscous remainder and the continuity flux, so ρ stays fixed for κ = 0. The constructor throws an ArgumentError for a negative μ, ζ or κ.

CompReS.CompressibleRates — Type
CompressibleRates

Linear rates of the Compressible model, from linear_rates, on the real-FFT layout of the grid ($\sigma(0) = 0$ in each array):

  • solenoidal: $\mu k^2 + \alpha k^{-2m}$ for the solenoidal part of the velocity.
  • compressive: $(\mu + \zeta) k^2 + \alpha k^{-2m}$ for the compressive part of the velocity.
  • density: $\kappa k^2$ for the density.
  • kx, ky: the grid wavenumbers, for the Helmholtz split inside the kernels. On the retained modes this split equals helmholtz_split!; the two differ only on the Nyquist column and row, where helmholtz_split! uses zero derivative wavenumbers.

CompReS.Grid — Type
Grid{T}

Periodic rectangle Lx × Ly with Nx × Ny points, equal spacing and float type T. Build it with Grid(; Lx, Ly, Nx, Ny, T = Float64, backend = CPU()).

The spectral arrays use the real-FFT layout (Nx ÷ 2 + 1, Ny), with kx along the first dimension and the second dimension in FFT order. The fields are:

  • kx, ky, k2: wavenumbers \hat{k}_x, \hat{k}_y and |\mathbf{k}|^2 (specification, Conventions).
  • truncation: true for the modes kept by the circular Galerkin truncation |\mathbf{k}| < k_c, k_c = (N_x/3)(2\pi/L_x) (specification, Galerkin truncation).
  • shell_index: n + 1 for the shell n of every grid mode, retained or not.
  • k_max: the largest retained |\mathbf{k}|.
  • Δk: the shell width 2\pi/\max(L_x, L_y).
  • shell_k, shell_edge, shell_count, shell_count_all (host vectors, entry n + 1 for shell n, up to the largest shell of any grid mode): the shell centre n Δk, the upper edge (n + 1/2) Δk, the number of retained modes, and the number of all grid modes. Both counts use the full wavenumber plane: weight 1 for the columns kx = 0 and kx = Nx/2, weight 2 elsewhere.

Shell n holds the modes with n - 1/2 ≤ |\mathbf{k}|/Δk < n + 1/2 (specification, Conventions). The constructor throws an ArgumentError for an odd Nx or Ny, and for unequal spacing |Lx/Nx - Ly/Ny| > 10^{-12} Lx/Nx.

CompReS.Incompressible — Type
Incompressible(; ν, large_scale = LargeScaleDissipation(), nonlinear = true)

Incompressible model with kinematic viscosity ν and the LargeScaleDissipation large_scale. Its linear part acts on each velocity mode as (specification, incompressible model, Fourier form)

\[\partial_t \hat u_i = -\big(\nu k^2 + \alpha k^{-2m}\big)\hat u_i .\]

nonlinear = false is a test switch: the right-hand side then drops the advection and keeps the linear terms and the forcing. The constructor throws an ArgumentError for ν < 0.

IncompressibleRates

Linear rates of the Incompressible model, from linear_rates. velocity holds $\sigma(\mathbf{k}) = \nu k^2 + \alpha k^{-2m}$ (with $\sigma(0) = 0$) on the real-FFT layout of the grid; both velocity components decay at this rate.

CompReS.KolmogorovForcing — Type
KolmogorovForcing(grid::Grid{T}; F, n)

Kolmogorov forcing, the single-mode shear acceleration (ADR-0007)

\[\mathbf{f} = F \sin(k_f y)\, \hat{\mathbf{x}}, \qquad k_f = n\, \frac{2\pi}{L_y}, \qquad \hat f_x(0, \pm k_f) = \mp \frac{iF}{2},\]

with support (0, \pm k_f). F is an acceleration (velocity per time); n is the mode index along y, as in kolmogorov. The forcing is solenoidal and has no state. The constructor throws an ArgumentError for n < 1 and for a mode outside the Galerkin truncation.

source
CompReS.LargeScaleDissipation — Type
LargeScaleDissipation(; α = 0, m = 0)

Large-scale dissipation $-\alpha(-\nabla^2)^{-m}\mathbf{u}$, with Fourier rate $\alpha k^{-2m}$ on every mode except $\mathbf{k} = 0$ (ADR-0004). m = 0 is linear friction; m ≥ 1 is hypoviscosity. The default α = 0 switches the term off. The constructor throws an ArgumentError for α < 0 or m < 0.

CompReS.OUForcing — Type
OUForcing(grid::Grid{T}, support; ε, τ_f, seed, compressive_fraction = 0, amp = Returns(1))

OU forcing on the forcing support (band, modes or support): each forced mode follows an independent complex Ornstein–Uhlenbeck process with correlation time τ_f (ADR-0007). update_forcing! advances it once per step Δt with the exact update

\[\hat{\mathbf{f}}(\mathbf{k}) \leftarrow e^{-\Delta t/\tau_f}\, \hat{\mathbf{f}}(\mathbf{k}) + \sqrt{1 - e^{-2\Delta t/\tau_f}}\; \sigma_k \big(\sqrt{1-\chi}\, \xi_s \hat{\mathbf{e}}_s + \sqrt{\chi}\, \xi_c \hat{\mathbf{e}}_c\big), \qquad \hat{\mathbf{e}}_s = \frac{(-k_y, k_x)}{|\mathbf{k}|}, \quad \hat{\mathbf{e}}_c = \frac{(k_x, k_y)}{|\mathbf{k}|},\]

with \chi = compressive_fraction and independent complex normal \xi_s, \xi_c, \langle|\xi|^2\rangle = 1. The stationary variance is \langle|\hat{\mathbf{f}}(\mathbf{k})|^2\rangle = \sigma_k^2, with

\[\sigma_k^2 = \frac{\varepsilon}{\tau_f}\, \frac{\mathrm{amp}(|\mathbf{k}|)^2}{\sum_{\mathbf{q}} w_{\mathbf{q}}\, \mathrm{amp}(|\mathbf{q}|)^2},\]

where the sum runs over the stored forced modes and w_{\mathbf{q}} is the half-plane weight (1 on the kx = 0 column, 2 elsewhere), so that \sum_{\mathbf{k}} \sigma_k^2 = \varepsilon/\tau_f over the full plane. For a velocity driven by the forcing alone, \partial_t\hat{\mathbf{u}} = \hat{\mathbf{f}}, the stationary mean injection rate is \sum_{\mathbf{k}} \mathrm{Re}\langle\hat{\mathbf{u}}^*\cdot\hat{\mathbf{f}}\rangle = \tau_f \sum_{\mathbf{k}}\sigma_k^2 = \varepsilon; in a flow, this holds when τ_f is short against the time over which the flow changes \hat{\mathbf{u}}. With the forcing held constant over a step, the injection ⟨u·f⟩ + ½Δt⟨|f|²⟩ of the time-discrete process is \varepsilon\, (\Delta t/2\tau_f) \coth(\Delta t/2\tau_f) = \varepsilon\,(1 + (\Delta t/\tau_f)^2/12 + \dots).

Units: ε is an energy injection rate per unit mass (velocity² per time), τ_f a time. amp(k), a function of the physical |\mathbf{k}|, is the dimensionless relative amplitude profile; only its ratios between modes matter. The forcing starts at \hat{\mathbf{f}} = 0 and reaches its stationary variance after a few τ_f.

seed and the step number n seed the random numbers of each step (see update_forcing!). A nonzero compressive_fraction needs the Compressible model; Problem checks it. The constructor throws an ArgumentError for a bad support (see support), ε < 0, τ_f ≤ 0, a compressive_fraction outside [0, 1], or an amp that is zero on every forced mode.

CompReS.Problem — Type

CompReS.RandomPhaseForcing — Type
RandomPhaseForcing(grid::Grid{T}, support; f_rms, τ_r, seed, compressive_fraction = 0, amp = Returns(1))

Random-phase forcing on the forcing support (band, modes or support): fixed amplitudes and random phases, all redrawn together every τ_r and constant in between (ADR-0007). On each forced mode

\[\hat{\mathbf{f}}(\mathbf{k}) = a_k \big(\sqrt{1-\chi}\, e^{i\varphi_s} \hat{\mathbf{e}}_s + \sqrt{\chi}\, e^{i\varphi_c} \hat{\mathbf{e}}_c\big), \qquad a_k^2 = f_{\rm rms}^2\, \frac{\mathrm{amp}(|\mathbf{k}|)^2}{\sum_{\mathbf{q}} w_{\mathbf{q}}\, \mathrm{amp}(|\mathbf{q}|)^2},\]

with \chi = compressive_fraction, phases \varphi uniform in [0, 2\pi), and the unit vectors and half-plane weights w_{\mathbf{q}} of OUForcing. Then \langle|\mathbf{f}|^2\rangle = \sum_{\mathbf{k}} |\hat{\mathbf{f}}(\mathbf{k})|^2 = f_{\rm rms}^2.

Units: f_rms is an acceleration (velocity per time), τ_r a time; amp(k) is the dimensionless relative amplitude profile of OUForcing.

update_forcing! redraws the phases at the multiples m τ_r of the reset period: at the start of the first step, and at each step that starts within Δt/2 of the next multiple. A step length that divides τ_r gives a redraw exactly every τ_r/Δt steps. A nonzero compressive_fraction needs the Compressible model; Problem checks it. The constructor throws an ArgumentError for a bad support (see support), f_rms < 0, τ_r ≤ 0, a compressive_fraction outside [0, 1], or an amp that is zero on every forced mode.

CompReS.State — Type
State(fields::NamedTuple; t = 0, n = 0)

The evolved fields of a run at time t and step n.

fields holds spectral fields in the real-FFT layout of the Grid, with element type Complex{T}: (ux, uy) for the incompressible model, or (ux, uy, rho) for the compressible model, whose state is (\mathbf{u}, \rho) (specification, compressible model; ADR-0002). The State keeps the given arrays, not copies. The time t takes the float type T of the fields.

The time loop changes t, n and the values in the arrays; the set of arrays stays fixed. The constructor throws an ArgumentError for other field names, and for fields of unequal size or element type.

CompReS.Transforms — Type
Transforms(grid::Grid)

FFT plans, derivative wavenumbers and scratch storage for one Grid. Build it once per grid and pass it to to_spectral!, to_physical!, ∂x!, ∂y!, helmholtz_split! and project_solenoidal!.

A physical field is a real Nx × Ny device array. A spectral field is a complex (Nx ÷ 2 + 1) × Ny device array in the real-FFT layout of the grid.

The fields are:

  • grid: the grid.
  • forward, inverse: the real-to-complex and complex-to-real FFT plans (FFTW with Threads.nthreads() threads on the CPU, cuFFT or rocFFT on a GPU). On the CPU, inverse also holds one spectral scratch array.
  • kx_deriv (length Nx ÷ 2 + 1), ky_deriv (length Ny): the derivative wavenumbers. They equal the grid wavenumbers, except that kx_deriv is zero on the Nyquist column kx = Nx/2 and ky_deriv is zero on the Nyquist row ky = Ny/2. The derivative multipliers are i k_x^{\rm d} and i k_y^{\rm d}.

The Nyquist mode of a real field has no sign: it stands for both +N/2 and -N/2. A nonzero multiplier there makes the discrete derivative of a real field complex. The zero multiplier keeps the derivative real and skew-adjoint, \sum f\,\partial_x g = -\sum g\,\partial_x f.

CompReS.Workspace — Type
Workspace(grid::Grid, state::State)

The Transforms of grid and the work arrays of the time loop, allocated once on the backend of the grid. The time loop allocates nothing else.

The fields are:

  • transforms: the Transforms of grid.
  • physical: a NamedTuple of real Nx × Ny arrays, one per state field and with the same name, for the physical-space values of that field (ux, uy and, compressible model only, rho).
  • vorticity: a real Nx × Ny array for the physical-space vorticity \omega (WP-6).
  • compressible: nothing for the incompressible model. For the compressible model, the buffers of its rhs! (WP-10): viscous_x, viscous_y, real Nx × Ny arrays for the physical-space \mu\nabla^2\mathbf{u} + \zeta\nabla\theta, and spectral, one spectral field.
  • forcing: a NamedTuple (ux, uy) of spectral fields for the forcing \hat{\mathbf{f}} of the current step, which update_forcing! writes (WP-9). They are zero outside the forcing support.

A work package adds its buffers as one more field of this struct, built in this constructor. A buffer per state field is a NamedTuple built with map over state.fields, as physical is; it then follows the model without a branch. Code reads a buffer by name, for example ws.physical.ux, and the typed fields keep every access type-stable.

CompReS.add_forcing! — Method
add_forcing!(dû, forcing::Union{KolmogorovForcing,OUForcing,RandomPhaseForcing}, state, workspace) -> dû

Add the forcing $\hat{\mathbf{f}}$ of the current step, stored in workspace.forcing by update_forcing!, to the velocity tendency dû.ux, dû.uy on the forced modes only. A density tendency dû.rho stays unchanged. The incompressible model needs a solenoidal $\hat{\mathbf{f}}$: with compressive_fraction = 0 the forcing is solenoidal by construction, $\mathbf{k}\cdot\hat{\mathbf{f}} = 0$, so it equals its projection, and Problem rejects a nonzero compressive fraction with the Incompressible model.

CompReS.band — Method
band(k_start, k_end)

The forcing band k_{\rm start} \le |\mathbf{k}| \le k_{\rm end}, in physical wavenumbers (not mode indices). The bounds are inclusive, with a relative tolerance of 8\,\mathrm{eps}(T) on |\mathbf{k}|^2 for the round-off of the grid wavenumbers. CompReS.enforce_hermitian! — Method
enforce_hermitian!(f̂, grid::Grid) -> f̂

Make the spectral field f̂ the transform of a real field with zero Nyquist modes. On the kx = 0 column the function copies the source half ky > 0 to the other half, \hat f(0, -k_y) = \hat f(0, k_y)^*, makes \hat f(0, 0) real, and sets the Nyquist column kx = Nx/2 and the Nyquist row ky = Ny/2 to zero.

The real-FFT layout stores both (0, k_y) and (0, -k_y). Every routine that generates spectral values directly (initial conditions, forcing) calls this function, so the spectral field and its physical field agree (ADR-0015).

CompReS.helmholtz_split! — Method
helmholtz_split!(ûs, ûc, û, tr::Transforms) -> (ûs, ûc)

Split the spectral vector field û = (ûx, ûy) into its solenoidal part ûs and its compressive part ûc (specification, compressible model, Helmholtz split):

\[\hat u^s_i = P_{ij}\hat u_j = \hat u_i - \frac{k_i k_j \hat u_j}{k^2}, \qquad \hat u^c_i = \frac{k_i k_j \hat u_j}{k^2}.\]

Each argument is a pair of spectral fields. The function uses the derivative wavenumbers of Transforms, so ∂x! and ∂y! give an exactly zero divergence of ûs and an exactly zero curl of ûc. Where these wavenumbers vanish (the k = 0 mode and the corner mode (Nx/2, Ny/2)), the whole mode is solenoidal: ûs = û, ûc = 0. ûs or ûc may be û.

CompReS.linear_tendency! — Method
linear_tendency!(dû, û, rates) -> dû

Add the linear terms $L\hat{\mathbf{u}}$ of the model to the tendency dû, for explicit time stepping. û and dû are spectral fields named (:ux, :uy) for IncompressibleRates and (:ux, :uy, :rho) for CompressibleRates. Per mode, $L\hat u_i = -\sigma\hat u_i$ in the incompressible model, and

\[L\hat{\mathbf{u}} = -\sigma_s\hat{\mathbf{u}}^s - \sigma_c\hat{\mathbf{u}}^c, \qquad L\hat\rho = -\sigma_\rho\hat\rho\]

in the compressible model, with the rates of linear_rates. The function allocates nothing.

CompReS.propagate! — Method
propagate!(out, û, rates, τ) -> out

Write $\exp(L\tau)\hat{\mathbf{u}}$, the integrating-factor propagator of the linear terms (ADR-0005), into out. The fields are named as in linear_tendency!; out may be û. Per mode, the propagator is $e^{-\sigma\tau}$ in the incompressible model, and

\[e^{L\tau}\hat{\mathbf{u}} = e^{-\sigma_s\tau} P\hat{\mathbf{u}} + e^{-\sigma_c\tau}(I - P)\hat{\mathbf{u}}, \qquad e^{L\tau}\hat\rho = e^{-\sigma_\rho\tau}\hat\rho\]

in the compressible model, with the solenoidal projection $P_{ij} = \delta_{ij} - k_ik_j/k^2$. The kernel computes the exponentials from the rates, so any τ (for example $c_i\Delta t$ of a Butcher table) costs no storage and no allocation. τ is converted to the float type of the rates.

CompReS.random_velocity — Method
random_velocity(grid::Grid{T}; spectrum, E_kin, seed) -> (; ux, uy)

A random solenoidal velocity field with shell spectrum proportional to spectrum(k) and kinetic energy E_kin, as spectral fields of float type T.

Each retained mode \mathbf{q} \neq 0 of shell n gets

\[\hat{\mathbf{u}}(\mathbf{q}) = a_n\, e^{i\varphi(\mathbf{q})}\, \frac{(-q_y, q_x)}{|\mathbf{q}|}, \qquad a_n^2 = c\, \frac{2\, \mathrm{spectrum}(k_n)}{M_n},\]

with k_n the shell centre, M_n the number of retained modes in shell n over the full plane (grid.shell_count) and a phase \varphi uniform in [0, 2\pi). The shell spectrum E(k_n) = \tfrac12 \sum_{\mathbf{q} \in k_n} |\hat{\mathbf{u}}(\mathbf{q})|^2 is then c\,\mathrm{spectrum}(k_n) (specification, incompressible model, spectra), and the factor c sets E_{\rm kin} = \tfrac12 \langle |\mathbf{u}|^2 \rangle = \sum_n E(k_n). The field is solenoidal, \mathbf{q} \cdot \hat{\mathbf{u}} = 0, lies inside the Galerkin truncation and has no mean flow. enforce_hermitian! sets the half ky < 0 of the kx = 0 column.

A Random.Xoshiro(seed) generator on the host draws the phases, and the host computes the field before the copy to the device, so one seed gives the same field on every backend, bit for bit. The function throws an ArgumentError when spectrum is zero on every retained mode.

CompReS.rhs! — Method
rhs!(dû, state, problem::Problem{<:Grid,<:Compressible}, workspace) -> dû

Write the tendency of the compressible model without its linear terms into dû (specification, compressible model, Fourier space):

\[\partial_t \hat\rho = -ik_j\, \widehat{\rho u_j}, \qquad \partial_t \hat u_i = -\widehat{(\omega\, \hat{\mathbf{z}} \times \mathbf{u})}_i - ik_i\, \widehat{\big(\tfrac12|\mathbf{u}|^2 + h(\rho)\big)} + \widehat{\Big[\Big(\frac1\rho - 1\Big)\big(\mu\nabla^2 u_i + \zeta\,\partial_i\theta\big)\Big]} + \hat f_i ,\]

restricted to the Galerkin truncation. The Lamb form $(\mathbf{u}\cdot\nabla)\mathbf{u} = \nabla(\tfrac12|\mathbf{u}|^2) + \omega\,\hat{\mathbf{z}}\times\mathbf{u}$ gives the advection (specification, notes for the numerical tests, note 2), and the enthalpy $h(\rho)$ of the equation of state gives the pressure term. The last term is the explicit remainder of the small-scale dissipation $\rho^{-1}(\mu\nabla^2\mathbf{u} + \zeta\nabla\theta)$ after its linear part with $\rho_0 = 1$ (ADR-0004). All products are evaluated in physical space. One evaluation takes 11 FFTs: 6 inverse ($u_x$, $u_y$, $\rho$, $\omega$ and the two components of $\mu\nabla^2\mathbf{u} + \zeta\nabla\theta$) and 5 forward (the two components of $-\omega\,\hat{\mathbf{z}}\times\mathbf{u}$ plus the remainder, $\tfrac12|\mathbf{u}|^2 + h$, and the two components of $\rho\mathbf{u}$). The forcing term $\hat f_i$ comes from add_forcing!.

The linear terms of linear_rates (the small-scale dissipation with $\rho_0 = 1$, the large-scale dissipation and the density diffusivity $-\kappa k^2\hat\rho$) are not part of dû. The time stepping adds them with linear_tendency!, or applies them with propagate! when it uses the integrating factor.

dû holds spectral fields named (:ux, :uy, :rho), of the size and element type of state.fields; the function overwrites every mode. The tendency of the mass $\langle\rho\rangle$ (the mode $\mathbf{k} = 0$ of dû.rho) is exactly zero. With nonlinear = false in the model, dû holds the forcing term only, so $\rho$ stays fixed for $\kappa = 0$. The function leaves state unchanged and overwrites the buffers physical, vorticity and compressible of workspace. It allocates no array.

source
CompReS.rhs! — Method
rhs!(dû, state, problem::Problem{<:Grid,<:Incompressible}, workspace) -> dû

Write the tendency of the incompressible model without its linear terms into dû:

\[\partial_t \hat u_i = -P_{il}(\mathbf{k})\, \widehat{(\omega\, \hat{\mathbf{z}} \times \mathbf{u})}_l + \hat f_i ,\]

restricted to the Galerkin truncation (specification, incompressible model, Fourier space). The Lamb form $(\mathbf{u}\cdot\nabla)\mathbf{u} = \nabla(\tfrac12|\mathbf{u}|^2) + \omega\, \hat{\mathbf{z}} \times \mathbf{u}$ gives the advection: the projector $P_{il}$ removes the gradient. One evaluation takes 5 FFTs: 3 inverse ($u_x$, $u_y$, $\omega$) and 2 forward. The forcing term $\hat f_i$ comes from add_forcing!.

The linear terms $-\sigma \hat u_i$ of linear_rates are not part of dû. The time stepping adds them with linear_tendency!, or applies them with propagate! when it uses the integrating factor.

dû holds spectral fields named (:ux, :uy), of the size and element type of state.fields; the function overwrites every mode. With nonlinear = false in the model, the advection is zero and dû holds the forcing term only. The function leaves state unchanged and overwrites the buffers physical and vorticity of workspace. It allocates no array.

CompReS.support — Method
support(pred)

The forcing support of the wavevectors \mathbf{k} with pred(kx, ky) == true, in physical wavenumbers k_x = 2\pi i/L_x, k_y = 2\pi j/L_y of the float type of the grid.

A forcing is a real field, so its support holds -\mathbf{k} with every \mathbf{k}: a mode is in the support when pred is true for \mathbf{k} or for -\mathbf{k}. A forcing constructor binds the support to its grid and throws an ArgumentError when the support is empty, holds the mode \mathbf{k} = 0, or holds a mode outside the Galerkin truncation. See also band and modes.

CompReS.to_physical! — Method
to_physical!(f, f̂, tr::Transforms) -> f

Write the real physical field f(\mathbf{x}) = \sum_{\mathbf{k}} \hat f(\mathbf{k}) e^{i\mathbf{k}\cdot\mathbf{x}} of the spectral field f̂ into f (specification, Conventions).

The function leaves f̂ unchanged on every backend, although a complex-to-real FFT overwrites its input: on the CPU, the inverse FFT runs in two stages through a scratch array; cuFFT and rocFFT transform a copy in a buffer of the plan. The transform uses only the ky ≥ 0 half of the kx = 0 column and of the Nyquist column; enforce_hermitian! makes the other half consistent with it.

CompReS.update_forcing! — Method
update_forcing!(forcing, state, workspace, Δt) -> workspace

Advance the state of forcing once, at the start of the step Δt from state.t (step state.n), and write the forcing $\hat{\mathbf{f}}$ of that step into workspace.forcing. The time stepping calls it once per step, before the first stage; $\hat{\mathbf{f}}$ stays constant over the step (ADR-0005).

  • NoForcing: no change; workspace.forcing stays zero.
  • KolmogorovForcing: writes the fixed field.
  • OUForcing: applies the exact OU update with step Δt.
  • RandomPhaseForcing: redraws the phases when the step starts a new period τ_r.

The random numbers of step n come from a Random.Xoshiro generator on the host, seeded from (seed, n); the host copies them to the device. Every backend then gets the same sequence, and a restart needs only the seed, the step and forcing_state. Every written $\hat{\mathbf{f}}$ passes through enforce_hermitian!. The update touches only the forced modes of workspace.forcing: its cost scales with the number of forced modes.
