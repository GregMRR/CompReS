Initial conditions

CompReS.crossed_kolmogorov — Method
crossed_kolmogorov(grid::Grid{T}; A1, k1, A2, k2) -> (; ux, uy)

The crossed Kolmogorov flow of the user acceptance test (ADR-0011),

\[\mathbf{u} = A_1 \sin(k_1 y)\, \hat{\mathbf{x}} + A_2 \sin(k_2 x)\, \hat{\mathbf{y}},\]

as spectral fields of float type T. k1 and k2 are integer mode indices, as n in kolmogorov: the wavenumbers are k1\, 2\pi/L_y and k2\, 2\pi/L_x. The function throws an ArgumentError for an index below 1 and for a mode outside the Galerkin truncation.

CompReS.kolmogorov — Method
kolmogorov(grid::Grid{T}; A, n) -> (; ux, uy)

The Kolmogorov flow \mathbf{u} = A \sin(k_n y)\, \hat{\mathbf{x}}, k_n = n\, 2\pi/L_y, as spectral fields of float type T (specification, Conventions):

\[\hat u_x(0, \pm k_n) = \mp \frac{iA}{2}, \qquad \hat u_y = 0.\]

n is the mode index along y, the same index as in crossed_kolmogorov. The function throws an ArgumentError for n < 1 and for a mode outside the Galerkin truncation.

CompReS.random_velocity — Method
random_velocity(grid::Grid{T}; spectrum, E_kin, seed) -> (; ux, uy)

A random solenoidal velocity field with shell spectrum proportional to spectrum(k) and kinetic energy E_kin, as spectral fields of float type T.

Each retained mode \mathbf{q} \neq 0 of shell n gets

\[\hat{\mathbf{u}}(\mathbf{q}) = a_n\, e^{i\varphi(\mathbf{q})}\, \frac{(-q_y, q_x)}{|\mathbf{q}|}, \qquad a_n^2 = c\, \frac{2\, \mathrm{spectrum}(k_n)}{M_n},\]

with k_n the shell centre, M_n the number of retained modes in shell n over the full plane (grid.shell_count) and a phase \varphi uniform in [0, 2\pi). The shell spectrum E(k_n) = \tfrac12 \sum_{\mathbf{q} \in k_n} |\hat{\mathbf{u}}(\mathbf{q})|^2 is then c\,\mathrm{spectrum}(k_n) (specification, incompressible model, spectra), and the factor c sets E_{\rm kin} = \tfrac12 \langle |\mathbf{u}|^2 \rangle = \sum_n E(k_n). The field is solenoidal, \mathbf{q} \cdot \hat{\mathbf{u}} = 0, lies inside the Galerkin truncation and has no mean flow. enforce_hermitian! sets the half ky < 0 of the kx = 0 column.

A Random.Xoshiro(seed) generator on the host draws the phases, and the host computes the field before the copy to the device, so one seed gives the same field on every backend, bit for bit. The function throws an ArgumentError when spectrum is zero on every retained mode.

CompReS.uniform_density — Method
uniform_density(grid::Grid{T}) -> (; rho)

The uniform density \rho = 1 as a spectral field of float type T: \hat\rho(\mathbf{0}) = 1 and every other mode is zero. Merge it with a velocity field to get the fields of a compressible State, for example merge(kolmogorov(grid; A, n), uniform_density(grid)).

CompReS.balanced_density — Method
balanced_density(u, eos, grid::Grid{T}) -> (; rho)

The density that balances the solenoidal velocity u at $t = 0$, as a spectral field of float type T (ADR-0013). u is a NamedTuple with the spectral fields ux and uy, for example the output of random_velocity or kolmogorov; eos is the equation of state of the run. Merge the result with u to get the fields of a compressible State: merge(u, balanced_density(u, eos, grid)).

A uniform $\rho$ with a solenoidal $\mathbf{u}$ emits acoustic waves of amplitude $O(Ma^2)$. For $\mu = \zeta = \kappa = 0$ and $\theta = \nabla\cdot\mathbf{u} = 0$, the compressible momentum equation (specification, compressible model) gives $\partial_t\theta = -\partial_i\partial_j(u_iu_j) - \nabla^2 h(\rho)$. The function makes this tendency zero in three steps:

  1. Solve the Poisson equation for the enthalpy on the Galerkin truncation, with zero mean:

\[\nabla^2 h = -\partial_i\partial_j(u_iu_j), \qquad \hat h(\mathbf{k}) = -\frac{k_ik_j\,\widehat{(u_iu_j)}(\mathbf{k})}{k^2} \quad (0 < |\mathbf{k}| < k_c), \qquad \hat h(\mathbf{0}) = 0 .\]

  1. Find the constant $h_0$ by a scalar root find (Newton steps with a bisection safeguard) such that

\[\big\langle \rho(h + h_0) \big\rangle = 1, \qquad \rho(h) = \texttt{density\_from\_enthalpy}(h) .\]

  1. Return $\hat\rho$, the Fourier coefficients of $\rho(h + h_0)$ on the grid, truncated to the disc.

The constant goes on $h$, not on $\rho$: a shift of $\rho$ after the inversion changes $\nabla h$ for a nonlinear $h(\rho)$. The truncation of $\hat\rho$ keeps the mean $\hat\rho(\mathbf{0}) = 1$ and leaves a residual of $\partial_t\theta(0)$ that falls spectrally with $N$. With viscosity, $\partial_t\theta(0) = O(\mu Ma^2)$, because $\partial_i(1/\rho)\nabla^2u_i \neq 0$. The products $u_iu_j$ are evaluated on the grid; for a velocity inside the truncation their aliases fall outside the disc, so $\hat h$ is exact on the disc.

The function converts eos to T (ADR-0006) and allocates its own Transforms and work arrays: call it once per run, before the time loop. It leaves u unchanged. The routine assumes a low Mach number: for Polytropic, $h + h_0$ must stay positive.
