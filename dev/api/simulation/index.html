Simulation

CompReS.Simulation — Type
Simulation(grid::Grid{T}, model; forcing = NoForcing(), scheme = RK4(), integrating_factor = true, Δt,
           outputs = (;), outdir, max_walltime = Inf, n_check = 10, C_stop = 1, profile = false,
           overwrite = false)

A run of model (Incompressible or Compressible) on grid, driven by forcing, with the time step Δt, the RungeKuttaScheme scheme and the integrating-factor switch integrating_factor. set_initial_condition! or restart! sets the state, and run! advances it and writes the output to the directory outdir.

The constructor converts the model (with its equation of state), the forcing, Δt and C_stop to the float type T of the grid (convert_float, ADR-0006). Without an initial condition, the state is at rest, with the density $\rho = 1$ in the compressible model.

Keywords:

  • outputs: a NamedTuple with one Output per sampled output class, under the keys GLOBAL, SPECTRAL and FIELDS. A class that is absent writes no file.
  • max_walltime: the wall-clock time in seconds after which run! writes a snapshot and stops.
  • n_check: the number of steps between two checks of the state (see run!).
  • C_stop: the largest CFL number that the checks accept. The CFL number is

    \[C = \Delta t\, \max_{\mathbf{x}} \Big[\frac{|u_x| + c}{\Delta x} + \frac{|u_y| + c}{\Delta y}\Big],\]

    with $c = 0$ in the incompressible model and $c = \max_{\mathbf{x}} c_s(\rho)$ in the compressible model (sound_speed²), over the grid points.
  • profile: true adds the times of the tasks of step! to the runtime log; on a GPU, the device synchronisations that this needs slow the run (ADR-0010).
  • overwrite: true lets a new run delete the output files of another run in outdir.

The constructor throws an ArgumentError for Δt ≤ 0, n_check < 1, C_stop ≤ 0, max_walltime < 0, an unknown output class or diagnostic name, a compressive forcing with the incompressible model (Problem), and for SSPRK3 with the integrating factor when its growth factor $e^{\sigma\Delta t/2}$ overflows the float type T on the largest linear rate $\sigma$. It warns when a forced run uses Euler or RK2: both are unstable on undamped oscillating modes.

The fields that a user reads are grid, problem (the Problem), state (the State), workspace (the Workspace), Δt, C_stop and cfl, the CFL number of the last check.

CompReS.cfl_number — Method
cfl_number(sim::Simulation) -> T

The CFL number of the state of sim (see Simulation), from the velocity and, compressible model, the sound speed at the grid points. The density must be positive. The function overwrites sim.workspace.physical and sim.workspace.vorticity.

CompReS.restart! — Method
restart!(sim::Simulation, path) -> sim

Restore the state of sim and the state of its forcing from the snapshot path (read_snapshot!); run! then continues that run in sim.outdir. sim must be set up as the run that wrote the snapshot (same grid size, model fields, forcing type and seed); Δt and the other driver settings may differ. The snapshot numbering continues after the index of path. The function throws an ArgumentError for a snapshot of another run.

CompReS.run! — Method
run!(sim::Simulation; t_end) -> sim

Advance sim from its current time $t_0$ to t_end, write the output classes of sim.outputs to sim.outdir and record the runtime log run.log (ADR-0009, ADR-0010).

Steps and times. The time of step $n$ is $t_n = t_0 + (n - n_0)\Delta t$, evaluated in Float64 from the step count and assigned to sim.state.t, so that the time does not drift by accumulated rounding. The run stops at the first step with $t_n \ge t_\mathrm{end} - \Delta t/2$, the step nearest to t_end.

Sampling. Each output class samples at $t_0$, then at the step nearest to each multiple $jP$ of its period $P$: step $n$ samples when $\lfloor (t_n + \Delta t/2)/P \rfloor$ exceeds its value at step $n - 1$. The multiples refer to $t = 0$, so a restart keeps the sampling times. At $t_0$ the injection rates inj_* are NaN, because no step has run (ADR-0019). GLOBAL and SPECTRAL append to global.nc and spectral.nc; FIELDS writes the snapshot fields/snap_NNNNNN.nc, numbered by the snapshot index, and params.toml holds the parameters with the driver settings under run.

Checks. At $t_0$ and every n_check steps, before the sampling, the run checks the state fields: every value finite (not NaN or Inf), the density positive at every grid point (compressible model), and the CFL number of Simulation at most C_stop. On a failure, run! writes a snapshot of the failed state and throws an ErrorException that names the failure.

Walltime. After each step, and at $t_0$, a wall-clock time since the call of at least max_walltime writes a snapshot and ends the call normally. Neither stop writes a second snapshot of a step that FIELDS has just sampled.

Files of a run. After set_initial_condition! (or at rest), run! starts a new run: it creates the files, and it throws an ArgumentError when outdir holds the files of another run, unless overwrite = true, which deletes them first. After restart! or a previous run!, the run continues: global.nc and spectral.nc keep their records of the steps before $n_0$ and drop the rest; run.log gets a new segment.

Runtime log. run.log holds a header per call, one progress line per FIELDS sample, the stop reason, and the TimerOutputs table, rewritten at each FIELDS sample and at the stop. The table times the steps, the checks, and each output class, with one entry per diagnostic; the remainder of a class is its file output. With profile = true, it also times the tasks of step!.

The function throws an ArgumentError for t_end before the current time.

CompReS.set_initial_condition! — Method
set_initial_condition!(sim::Simulation, fields::NamedTuple) -> sim

Copy the spectral fields into the state of sim and set t = 0 and n = 0; run! then starts a new run. fields holds ux and uy and, compressible model only, optionally rho; without rho the density is uniform, $\rho = 1$. The initial-condition functions return such fields, for example random_velocity; merge combines a velocity with a density. The function throws an ArgumentError for a missing velocity component, a field that the model does not evolve, or a field of another size.
