Diagnostics

CompReS.Diagnostic — Type
Diagnostic

A registered diagnostic: the function f(state, problem, workspace) and the coordinate of its values. A GLOBAL diagnostic returns one number of the float type T of the state and has the coordinate :none. A SPECTRAL diagnostic returns a Vector{T} with one value per shell of the grid, and its coordinate names the Grid field of the wavenumbers where the values are reported: :shell_k (shell centres) or :shell_edge (upper shell edges). Calling a Diagnostic with (state, problem, workspace) calls f.

A diagnostic is a generic function: one registration serves every model, and each model adds its method (ADR-0022).

CompReS.record_injection! — Method
record_injection!(problem, state, workspace, Δt) -> workspace

Store the injection rates of the step Δt that starts at state in workspace.diagnostics.injection, under the names of their GLOBAL diagnostics. The time stepping calls it once per step, right after update_forcing!, so state holds $\hat{\mathbf{u}}_n$ and workspace.forcing holds $\hat{\mathbf{f}}_n$ (ADR-0016, ADR-0017). A diagnostic sees the state after the step, so the inj_* diagnostics read the stored values; a rate not yet stored reads as NaN.

This method, for any problem without its own method, stores nothing.

CompReS.register_diagnostic! — Method
register_diagnostic!(class::Symbol, name::Symbol, f; coordinate = :shell_k) -> Diagnostic

Register the function f(state, problem, workspace) as the diagnostic name of the output class class, :GLOBAL or :SPECTRAL (ADR-0009). coordinate applies to :SPECTRAL only: :shell_k for values at the shell centres $k_n = n\Delta k$, :shell_edge for values at the upper shell edges $K_n = (n + \tfrac12)\Delta k$. A new registration under an existing name replaces the old one.

The function throws an ArgumentError for another class or coordinate.

CompReS.enstrophy — Method
enstrophy(state, problem, workspace) -> T

The enstrophy, GLOBAL diagnostic Z, in both models (specification, invariants). The vorticity is band-limited, so the sum over the stored modes equals the grid mean:

\[Z = \tfrac12\langle\omega^2\rangle = \tfrac12 \sum_{\mathbf{k}} |\hat\omega(\mathbf{k})|^2, \qquad \hat\omega = i(k_x \hat u_y - k_y \hat u_x) .\]

CompReS.enstrophy_flux — Method
enstrophy_flux(state, problem, workspace) -> Vector{T}

The enstrophy flux, SPECTRAL diagnostic Pi_Z, at the upper shell edges $K_n = (n + \tfrac12)\Delta k$ (grid.shell_edge). In the incompressible model (specification, incompressible model, fluxes):

\[\Pi_Z(K_n) = \sum_{|\mathbf{q}| < K_n} \mathrm{Re}\big[\hat\omega^*(\mathbf{q})\, \widehat{\mathbf{u}\cdot\nabla\omega}(\mathbf{q})\big] .\]

$\widehat{\mathbf{u}\cdot\nabla\omega}$ is the curl of $\hat{\mathbf{N}}$. The shells and the buffers are those of kinetic_energy_flux.

\[Z(k_n) = \tfrac12 \sum_{\mathbf{q} \in k_n} |\hat\omega(\mathbf{q})|^2 .\]

CompReS.kinetic_energy_flux — Method
kinetic_energy_flux(state, problem, workspace) -> Vector{T}

The kinetic-energy flux, SPECTRAL diagnostic Pi_kin, at the upper shell edges $K_n = (n + \tfrac12)\Delta k$ (grid.shell_edge). In the incompressible model, with $\mathbf{N} = (\mathbf{u}\cdot\nabla)\mathbf{u}$ (specification, incompressible model, fluxes):

\[\Pi_E(K_n) = \sum_{|\mathbf{q}| < K_n} \mathrm{Re}\big[\hat{\mathbf{u}}^*(\mathbf{q}) \cdot \hat{\mathbf{N}}(\mathbf{q})\big] .\]

Entry n + 1 sums the shells 0, …, n. It equals the specification's $\Pi_E(K)$ for every K from the largest $|\mathbf{q}|$ in these shells up to $K_n$, without $K_n$ itself: a mode with $|\mathbf{q}| = K_n$ belongs to shell n + 1 (WP-8). $\hat{\mathbf{N}}$ is the advection of rhs!, also for nonlinear = false. The function overwrites the buffers physical, vorticity and diagnostics.nonlinear of workspace.

\[E(k_n) = \tfrac12 \sum_{\mathbf{q} \in k_n} |\hat{\mathbf{u}}(\mathbf{q})|^2 .\]

CompReS.record_injection! — Method
record_injection!(problem::Problem{<:Grid,<:Incompressible}, state, workspace, Δt) -> workspace

Store the injection rates of $E_{\rm kin}$ and $Z$ for the step Δt as inj_E_kin and inj_Z. With $\hat{\mathbf{u}}$ and $\hat{\mathbf{f}}$ at the start of the step and the forcing constant over the step (WP-8, ADR-0015):

\[\mathrm{inj}_{E} = \sum_{\mathbf{k}} \Big(\mathrm{Re}\big[\hat{\mathbf{u}}^* \cdot \hat{\mathbf{f}}\big] + \tfrac12 \Delta t\, |\hat{\mathbf{f}}|^2\Big), \qquad \mathrm{inj}_{Z} = \sum_{\mathbf{k}} k^2 \Big(\mathrm{Re}\big[\hat{\mathbf{u}}^* \cdot \hat{\mathbf{f}}\big] + \tfrac12 \Delta t\, |\hat{\mathbf{f}}|^2\Big) .\]

The sums run over the full plane: the stored modes have the half-plane weight 1 on the kx = 0 column and the Nyquist column, 2 elsewhere. The $\tfrac12\Delta t|\hat{\mathbf{f}}|^2$ term removes the $O(\Delta t/\tau_f)$ bias of the plain product: with forcing only, the rate equals $(E_{\rm kin}(t_{n+1}) - E_{\rm kin}(t_n))/\Delta t$.

CompReS.density_diffusion_internal_energy — Method
density_diffusion_internal_energy(state, problem, workspace) -> T

The density-diffusion rate of $E_{\rm int}$, GLOBAL diagnostic kappa_E_int of the compressible model, with the enthalpy $h(\rho)$ of the equation of state (specification, compressible model, local balances):

\[\kappa\,\langle h(\rho)\,\nabla^2\rho\rangle = -\kappa\,\langle h'(\rho)\,|\nabla\rho|^2\rangle \le 0 .\]

The code evaluates the left form, the exact rate of the semi-discrete system (ADR-0025).

CompReS.kinetic_energy_flux — Method
kinetic_energy_flux(state, problem::Problem{<:Grid,<:Compressible}, workspace) -> Vector{T}

The kinetic-energy flux, SPECTRAL diagnostic Pi_kin, in the compressible model, at the upper shell edges $K_n = (n + \tfrac12)\Delta k$ (grid.shell_edge), over all grid modes (specification, compressible model, fluxes):

\[\Pi_K(K_n) = \sum_{|\mathbf{q}| < K_n} \mathrm{Re}\big[\hat{\mathbf{w}}^* \cdot \hat{\mathbf{N}}^w\big], \qquad N^w_i = \sqrt\rho\,u_j\partial_j u_i + \frac{u_i}{2\sqrt\rho}\,\partial_j(\rho u_j) .\]

The advection takes the Lamb form $u_j\partial_j u_i = \partial_i(\tfrac12|\mathbf{u}|^2) + (\omega\,\hat{\mathbf{z}}\times\mathbf{u})_i$, with spectral derivatives of the grid fields $\tfrac12|\mathbf{u}|^2$ and $\rho\mathbf{u}$ and no truncation. The flux over all grid modes, the last entry, is then zero to round-off (specification, note 2). The shells follow kinetic_energy_flux of the incompressible model.

kinetic_energy_flux_comp(state, problem, workspace) -> Vector{T}

The compressive part of the kinetic-energy flux, SPECTRAL diagnostic Pi_kin_comp of the compressible model, at the upper shell edges $K_n$ (grid.shell_edge) (see kinetic_energy_flux_inc):

\[\Pi_K^{\rm comp}(K_n) = \sum_{|\mathbf{q}| < K_n} \mathrm{Re}\big[\hat{\mathbf{w}}^{c*} \cdot \hat{\mathbf{N}}^w\big] .\]

CompReS.kinetic_energy_flux_inc — Method
kinetic_energy_flux_inc(state, problem, workspace) -> Vector{T}

The solenoidal part of the kinetic-energy flux, SPECTRAL diagnostic Pi_kin_inc of the compressible model, at the upper shell edges $K_n$ (grid.shell_edge), with $\hat{\mathbf{w}}^s$ of kinetic_energy_inc and $\hat{\mathbf{N}}^w$ of kinetic_energy_flux:

\[\Pi_K^{\rm inc}(K_n) = \sum_{|\mathbf{q}| < K_n} \mathrm{Re}\big[\hat{\mathbf{w}}^{s*} \cdot \hat{\mathbf{N}}^w\big], \qquad \Pi_K = \Pi_K^{\rm inc} + \Pi_K^{\rm comp} .\]

CompReS.kinetic_energy_inc — Method
kinetic_energy_inc(state, problem, workspace) -> T

The solenoidal kinetic energy, GLOBAL diagnostic E_kin_inc of the compressible model, a sum over all grid modes of the solenoidal part $\hat{\mathbf{w}}^s = P\hat{\mathbf{w}}$ of helmholtz_split! (specification, compressible model, spectra):

\[E_{\rm kin}^{\rm inc} = \tfrac12 \sum_{\mathbf{k}} |\hat{\mathbf{w}}^s(\mathbf{k})|^2 .\]

kinetic_energy_comp gives the compressive part; the two add up to $E_{\rm kin}$. On the Nyquist column and row the derivative wavenumbers vanish, so these modes count as solenoidal in one direction.

CompReS.potential_enstrophy_flux — Method
potential_enstrophy_flux(state, problem, workspace) -> Vector{T}

The potential-enstrophy flux, SPECTRAL diagnostic Pi_Omega of the compressible model, at the upper shell edges $K_n = (n + \tfrac12)\Delta k$ (grid.shell_edge), over all grid modes (specification, compressible model, fluxes):

\[\Pi_\Omega(K_n) = \sum_{|\mathbf{q}| < K_n} \mathrm{Re}\big[\hat s^*\,\hat N^s\big], \qquad N^s = \frac{\partial_j(u_j\omega)}{\sqrt\rho} - \frac{\omega}{2\rho^{3/2}}\,\partial_j(\rho u_j) .\]

The derivatives are spectral on the grid fields $u_j\omega$ and $\rho u_j$, without truncation. The non-polynomial factors leave an aliasing floor at $k_{\max}$ (specification, note 2).

CompReS.record_injection! — Method
record_injection!(problem::Problem{<:Grid,<:Compressible}, state, workspace, Δt) -> workspace

Store the injection rates of $E_{\rm kin}$ and $\Omega$ for the step Δt as inj_E_kin and inj_Omega. With $\mathbf{u}$, $\rho$ and the forcing $\mathbf{f}$ at the start of the step, the forcing constant over the step and $q = \omega/\rho$ (specification, compressible model, global budgets; WP-11):

\[\mathrm{inj}_{E} = \langle\rho\,\mathbf{u}\cdot\mathbf{f}\rangle + \tfrac12\Delta t\,\langle\rho|\mathbf{f}|^2\rangle, \qquad \mathrm{inj}_{\Omega} = \langle q \operatorname{curl}\mathbf{f}\rangle + \tfrac12\Delta t\,\langle(\operatorname{curl}\mathbf{f})^2/\rho\rangle .\]

The means are grid means of the physical fields. The $\tfrac12\Delta t$ terms remove the $O(\Delta t/\tau_f)$ bias of the plain products: with forcing only and fixed $\rho$, the rates equal $(E_{\rm kin}(t_{n+1}) - E_{\rm kin}(t_n))/\Delta t$ and the same for $\Omega$.

CompReS.small_scale_energy_dissipation — Method
small_scale_energy_dissipation(state, problem::Problem{<:Grid,<:Compressible}, workspace) -> T

The small-scale dissipation rate of $E_{\rm kin}$, GLOBAL diagnostic dissS_E_kin, in the compressible model: the mean viscous dissipation $\langle D\rangle$, $D = \tau_{ij}\partial_j u_i$, which in a periodic domain reads (specification, compressible model, local balances)

\[\langle D\rangle = \mu\langle\partial_j u_i\,\partial_j u_i\rangle + \zeta\langle\theta^2\rangle = \sum_{\mathbf{k}} \Big(\mu k^2 |\hat{\mathbf{u}}|^2 + \zeta |\mathbf{k}\cdot\hat{\mathbf{u}}|^2\Big) .\]

source
CompReS.small_scale_potential_enstrophy_dissipation — Method
small_scale_potential_enstrophy_dissipation(state, problem, workspace) -> T

The small-scale dissipation rate of $\Omega$, GLOBAL diagnostic dissS_Omega of the compressible model, with $q = \omega/\rho$ and $\mathbf{g} = \rho^{-1}(\mu\nabla^2\mathbf{u} + \zeta\nabla\theta)$ (specification, compressible model, global budgets):

\[-\langle q \operatorname{curl}\mathbf{g}\rangle .\]

The curl is spectral on the grid values of $\mathbf{g}$. The rate has no fixed sign; for uniform $\rho = \rho_0$ it equals $\mu\langle|\nabla\omega|^2\rangle/\rho_0^2$.

CompReS.total_energy — Method
total_energy(state, problem, workspace) -> T

The total energy, GLOBAL diagnostic E_tot of the compressible model, conserved for $\mu = \zeta = \kappa = \alpha = 0$ without forcing (specification, compressible model, invariants):

\[E_{\rm tot} = E_{\rm kin} + E_{\rm int} .\]
