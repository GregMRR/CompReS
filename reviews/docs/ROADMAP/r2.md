## Findings
### E20 [major] No planned test enforces Hermitian symmetry of generated spectral fields on the kx = 0 column, and the OU test passes on a non-Hermitian generator
- Where: ROADMAP:153-156 (WP-9), ROADMAP:122 (WP-4 `random_velocity`, "random phases"); r1 E3.
- Evidence: in the real-FFT layout the stored kx = 0 column holds both (0, ky) and (0, −ky). A generator that draws an independent value for each stored support mode is not Hermitian. Both c2r libraries then keep only the Hermitian part. The planned test sums stored modes, `Σ_support w_k Re[û*·f̂]`, so it cannot see the defect. `r2-E20.jl` (N = 32, band(4, 6), M = 4000, seed 11) finds 37 stored support modes, 6 of them at kx = 0. Hermitian generator: spectral 68.28, physical ⟨u·f⟩ 68.28. Non-Hermitian generator: spectral 68.27, physical 65.24, ratio 0.956. The test passes and the physical injection is 4.4% low.
- Consequence: the injected energy, and every spectral diagnostic (E_kin, spectra and fluxes computed from û), disagree with the physical field. The anti-Hermitian part of the kx = 0 column grows as a random walk under the forcing, and no part of the dynamics sees it. `random_velocity` has the same trap with its random phases.
- Hint: require Hermitian symmetry on the kx = 0 column (and k = 0 real) for every generated spectral field, and test it directly (`f̂(0,−ky) == conj(f̂(0,ky))`), or compute the test injection as the grid mean of `irfft(û)·irfft(f̂)`.
- Resolution: _(author)_

### E21 [major] The balanced-density procedure of ADR-0013, as written, does not give ∂_tθ(0) = 0, and the WP-14 "to round-off" target also depends on whether ρ̂ is truncated and on N
- Where: ADR-0013:5 ("applies `density_from_enthalpy`, and shifts the constant so that ⟨ρ⟩ = 1"); ROADMAP:183; r1 E13.
- Evidence: the sentence orders the steps "apply density_from_enthalpy", then "shift the constant", so the natural reading is ρ += 1 − ⟨ρ⟩. For a nonlinear h(ρ) this changes ∇h(ρ). `r2-E21.jl` (isothermal, c_s = 10, Ma = 0.1) reports max|∂_tθ̂| / max|k_ik_j(u_iu_j)^|:
  - Additive ρ shift: 1.3e-5 (cellular flow) and 1.6e-5 (three-mode flow), at every N from 16 to 64.
  - Shift of h (here ρ ./= ⟨ρ⟩, exact only for the isothermal EOS), ρ̂ not truncated: 6e-14 to 1.1e-12 (round-off).
  - Shift of h, ρ̂ truncated to the disc: 1.0e-8 (cellular, N = 16) and 1.7e-5 (three-mode, N = 16); round-off only from N = 32 or 64.
- Consequence: an agent that follows ADR-0013 literally fails WP-14 and has no stated correct procedure. The obvious workaround (ρ ./= ⟨ρ⟩) is wrong for `Polytropic`. On the N = 8 or 16 test grids that CLAUDE.md:23 prescribes, the test fails even with the correct shift, unless ρ̂ is left untruncated. Either path invites a silent loosening of the tolerance.
- Hint: specify "add a constant h₀ to h and solve ⟨ρ(h + h₀)⟩ = 1 (scalar root find)", state whether `balanced_density` truncates ρ̂, and state the EOS, the flow and the N of the round-off test.
- Resolution: _(author)_
